# GitHub community spaces

GitHub Discussions is enabled for this repository. Use discussions for project introductions, open-ended design questions and feedback that may help other users. Use issues for specific, actionable work with acceptance criteria.

## Current discussions

- [Présentation de Terraform Change Review](https://github.com/riadh-mnasri/terraform-change-review/discussions/22) introduces the maintainer and the project's purpose, implementation boundaries and feedback channel.
- [Quels changements faut-il repérer en priorité dans un plan Terraform ?](https://github.com/riadh-mnasri/terraform-change-review/discussions/23) asks users which Terraform plan changes they review first and what evidence is useful.

These conversations present the maintainer's work through a concrete open-source project and invite technical feedback. Keep future announcements factual: describe implemented behavior, cite the repository, and state current limits.

For a code change or an implementation proposal with acceptance criteria, use an [issue](https://github.com/riadh-mnasri/terraform-change-review/issues). Do not post production Terraform plans, credentials, private infrastructure details or other sensitive data in public discussions.

The repository also provides [custom GitHub agent profiles](github-agents.md) for evidence-based plan review and open-source maintenance.
