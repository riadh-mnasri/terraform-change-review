## Terraform Change Review v0.1.0

Initial public release: a local Java 17+ CLI and stdio MCP server for evidence-based Terraform plan reviews.

### Included

- Resource and output change inventory across providers.
- Eleven targeted rules: destructive actions and selected GCP IAM, firewall, storage, GKE and Cloud SQL changes.
- IAM condition removal detection and expression-change reporting, without claiming to evaluate CEL implication.
- Per-rule coverage: EXECUTED, SKIPPED with a reason, and NOT_SUPPORTED for items without specialized checks.
- Strict plan structure/type validation and diagnostic codes without echoing input content.
- Explicit unknown plan completeness (`complete: null`) when Terraform does not report it.
- JSON and Markdown reports, sensitivity-mask redaction and local path confinement.
- Regression tests, full plan fixtures generated by Terraform 1.15.7 and official MCP SDK integration tests.
- Maven Wrapper 3.3.2 with a pinned Maven 3.9.9 distribution and SHA-256 checks.

### Installation

Download `terraform-change-review-0.1.0.jar` and `SHA256SUMS` from this release.
Verify the checksum, then run with Java 17+:

```sh
shasum -a 256 -c SHA256SUMS
java -jar terraform-change-review-0.1.0.jar --help
```

See the README for Claude Code registration and examples. Release checksums verify
file integrity against the published manifest; artifacts are not cryptographically
signed by the maintainer.

### Scope and limitations

This is an early, deliberately partial reviewer, not an apply approval gate.
No findings does not mean safe. No live cloud state, effective IAM evaluation,
network reachability simulation, cost prediction or comprehensive provider coverage.
Generated Terraform fixtures cover the built-in provider; GCP checks use synthetic
regression scenarios. A broad Google provider compatibility matrix is not claimed.

Claude Code 2.1.325 connected to the local server during validation. The model-backed
conversation smoke test could not finish because its API requests failed in the
execution environment; MCP tool execution is separately verified by SDK integration tests.
